# App Control Stock Synergy

App de Power Apps para el control del almacén de Synergy Nox:
- entradas de material desde albaranes y facturas;
- salidas a los proyectos;
- stock por lugar y grupo, con avisos;
- historial de precios por proveedor;
- listado PDF para el recuento y regularización contra el Job 1111.
